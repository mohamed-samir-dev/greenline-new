# جرين لاين — Green Line

متجر أسمدة تجريبي كامل الواجهة مبني باستخدام Next.js App Router وReact وTypeScript.

## التشغيل

يتطلب Node.js 20.9 أو أحدث.

```sh
npm install
npm run dev
```

افتح العنوان الذي يظهر في الطرفية (عادة http://127.0.0.1:3000).

## نسخة الإنتاج

```sh
npm run build
```

يتم إنشاء موقع ثابت في مجلد `out` يصلح للاستضافة الثابتة. لأن المشروع يستخدم static export، لا تستخدم `next start` لتشغيل الناتج؛ قدم مجلد `out` باستخدام خادم ملفات ثابتة.

## تعديل المتجر

- المنتجات والأسعار ومعدل التحويل: `app/products.ts`.
- الواجهة والسلة ونموذج الطلب: `app/page.tsx`.
- التصميم المتجاوب: `app/globals.css`.
- العنوان والوصف: `app/layout.tsx`.
- سعر الصرف التجريبي: 1 ريال سعودي = 13 جنيه مصري؛ ليس سعرًا مباشرًا.

## ما يعمل

واجهة عربية RTL، ستة منتجات، بحث وتصنيفات وترتيب الأسعار، تفاصيل المنتج، سلة محفوظة على نفس المتصفح، تعديل الكميات وحذف المنتجات، عنوان توصيل مع تحقق من المدخلات، اختيار مصر أو السعودية لتحديد عملة الدفع، دفع عند الاستلام فقط، وتأكيد طلب تجريبي مع رقم مرجعي.

## حدود النسخة التجريبية

لا توجد قاعدة بيانات أو استقبال طلبات لدى تاجر أو إرسال رسائل أو تكامل شحن. بيانات الاتصال والعنوان لا تُحفظ ولا تُرسل. تأكيد الطلب موجود في ذاكرة الصفحة فقط، والسلة هي فقط ما يُحفظ في localStorage. المنتجات والأوصاف والصور والأسعار وهمية. صورة العبوة مشتركة توضيحية وليست تمثيلًا دقيقًا لكل منتج. لا توجد مدفوعات إلكترونية.

لتشغيل متجر حقيقي، يلزم ربط الطلبات بواجهة خادم وقاعدة بيانات، إضافة صلاحيات إدارة آمنة، وتحديد أسعار الصرف والشحن والضرائب وسياسات المتجر الفعلية.
